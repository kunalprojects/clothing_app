# VIBE E-commerce Demo - Client Guide

## 🎯 What This Demo Includes

This is a **fully functional prototype** of your Gen Z clothing brand e-commerce website. Everything you see works in real-time in your browser!

## 🚀 How to Run the Demo

### Option 1: View it Now (If Developer Has Started It)
Simply open your browser and go to: **http://localhost:3000**

### Option 2: Start it Yourself
1. Open Terminal/Command Prompt
2. Navigate to the project folder
3. Run: `npm run dev`
4. Open browser to: **http://localhost:3000**

## 🛍️ What You Can Do in This Demo

### **Homepage** (http://localhost:3000)
- See the hero banner with your brand message
- Browse collection tiles
- View new arrivals and best sellers
- Read brand story
- Check social proof numbers
- See customer reviews
- Sign up for newsletter (UI only)

### **Shop All Products** (http://localhost:3000/shop)
- Filter by category (T-Shirts, Bottoms, Hoodies, etc.)
- Filter by price range
- Sort products (Featured, New, Price Low-High, High-Low)
- Quick add to cart from product cards
- Add products to wishlist

### **Individual Product Pages**
- Click any product to see detailed page
- View multiple product images
- Select size and color
- Change quantity
- Add to cart or wishlist
- Read product details (fabric, fit guide, care instructions)
- See customer reviews
- Browse related products

### **Shopping Cart** (Click bag icon in header)
- Slide-out drawer shows cart items
- Update quantities
- Remove items
- See subtotal calculation
- Proceed to checkout

### **Checkout** (http://localhost:3000/checkout)
- Fill in contact information
- Enter shipping address
- Choose payment method (UPI, Card, Net Banking, COD)
- See order summary with all items
- Place order (simulated - won't charge real money)

### **Wishlist** (Heart icon in header)
- Save favorite products
- View all wishlisted items
- Quick access to add to cart

### **Other Pages**
- **About Us**: Brand story and team (http://localhost:3000/about)
- **Contact**: Contact form and info (http://localhost:3000/contact)
- **FAQ**: Common questions (http://localhost:3000/faq)
